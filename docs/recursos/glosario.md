# Glosario

Vocabulario mínimo del curso. Cada término aparece por primera vez en el proyecto que se indica, siempre **después** de que lo hayas observado en la práctica.

## Proyecto 1 · Fundamentos

- **Bit** — la unidad mínima de información: dos estados posibles.
- **Byte** — ocho bits. La unidad con que se mide el tamaño de los archivos.
- **Codificación** — la regla que asocia símbolos con números. Un archivo de texto es números interpretados con una regla.
- **Memoria** — almacenamiento rápido y volátil: se borra al apagar.
- **Almacenamiento** — lento y persistente: sobrevive al apagado. No es lo mismo que memoria.
- **Procesador** — el componente que ejecuta las instrucciones.
- **Sistema operativo** — el programa que administra los recursos de la máquina y permite que los demás programas existan.
- **Sistema de archivos** — la estructura que organiza el almacenamiento en carpetas y archivos.

## Proyecto 2 · Sistemas de información y algoritmos

- **Dato** — un hecho registrado, sin interpretación.
- **Información** — datos organizados que responden una pregunta.
- **Sistema de información** — el conjunto de personas, procedimientos y recursos que captura, guarda y entrega información para tomar decisiones. Puede no tener ninguna computadora.
- **Proceso** — secuencia de actividades que transforma entradas en salidas.
- **Algoritmo** — procedimiento no ambiguo y finito para resolver un problema.
- **Pseudocódigo** — algoritmo escrito en lenguaje estructurado, entre el español y un lenguaje de programación.
- **Validación** — comprobar que un dato cumple las condiciones antes de usarlo.
- **Prueba de escritorio** — ejecutar un algoritmo a mano, anotando el valor de cada variable en cada paso.
- **TPS, MIS, DSS, ERP** — tipos de sistema según qué decisión soportan.

## Proyecto 3 · Bases de datos

- **Entidad** — un tipo de cosa sobre la que se guardan datos: clientes, productos, ventas.
- **Atributo** — una característica de una entidad.
- **Registro** — una ocurrencia concreta de una entidad. Un renglón.
- **Clave primaria** — el atributo que identifica sin ambigüedad a cada registro.
- **Clave foránea** — el atributo que apunta a la clave primaria de otra tabla.
- **Integridad referencial** — la garantía de que toda clave foránea apunta a algo que existe.
- **Redundancia** — el mismo dato guardado en varios lugares, con el riesgo de que dejen de coincidir.
- **Consulta** — una pregunta hecha a la base de datos.
- **DBMS** — el programa que administra la base de datos e impone sus reglas.

## Transversales

- **Modelo de lenguaje** — sistema entrenado para predecir texto. No consulta hechos: genera texto probable, y por eso puede inventar con formato impecable.
- **Alucinación** — respuesta falsa presentada con la misma seguridad que una verdadera.
- **Verificación** — comprobar una afirmación contra una fuente independiente. Es la operación central de este curso.
